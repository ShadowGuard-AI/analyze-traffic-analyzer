Charge of the Watch

analyze-traffic-analyzer analyses network traffic patterns, a short purpose the source files under data analysis and reporting. The entry says only that, in that plain form, because this tool's document is brief and the page is brief where its source is brief.

What the Log Is Kept From

The input is a CSV file, and the log is kept from two columns the source insists on: source_ip and data_transferred. The report counts distinct source IP values and sums the data transferred column, and no other reading is offered. Destination addresses are not counted, a limit this entry records in the same paragraph, not in a footnote.

The Counted Night

The one verified example the source gives, set as a ruled tally with its values exactly as documented and no second example invented to keep it company:

100, 50, 25data values in the sample
2unique IPs reported
175total data transferred

Results are reported through log lines, not printed output. When an output file is given, the report is also written as a CSV with the columns Unique IPs and Total Data Transferred. Those two destinations are labelled here in the order the source presents them, log first and file second.

Rigging and Running

pip install -r requirements.txt
python3 main.py <input_file> [--output_file <output_file>]

A missing input file exits 1, and the column names must match exactly or the count the tool promises is not the count it can make.
